# Ahmad Nouh — portfolio & AI Twin

[Live portfolio](https://me.nouhlab.com/) · [GitHub](https://github.com/ahmadnouh97)

A portfolio built with Vite, TypeScript, CSS, and Cloudflare Pages Functions. The AI Twin uses Groq's `openai/gpt-oss-120b`; explicit contact submissions send an email through Resend. Turnstile protects both routes.

## Run locally

Use Node.js **24** and npm.

```sh
npm ci
npm run build
npm run check
npm run preview
```

The complete Pages preview runs at http://127.0.0.1:8788. `npm run dev` runs only the Vite frontend at port 5173. HTML is generated by `scripts/render.ts` before each build.

## Automatic deployment

The [Deploy portfolio workflow](.github/workflows/deploy.yml) runs on every **push to `main`**, including merged pull requests. It installs locked dependencies, builds the static site, runs the existing checks, and deploys `dist/` plus the Pages Functions to `ahmad-nouh-portfolio`. Production remains at **https://me.nouhlab.com**.

Other branches do not deploy. Manual deployment is available under **Actions → Deploy portfolio → Run workflow**. Production runs are serialized to avoid overlapping deployments.

GitHub Actions configuration:

| Setting | Type | Value |
| --- | --- | --- |
| `CLOUDFLARE_ACCOUNT_ID` | Repository variable | Account containing the Pages project |
| `CLOUDFLARE_API_TOKEN` | Encrypted repository secret | Token restricted to that account, with **Account → Cloudflare Pages → Edit** |

The Groq, Resend, and Turnstile secrets remain in Cloudflare. They are not required in GitHub Actions or in the frontend build. A failed build or check prevents deployment.

This uses GitHub-hosted Linux runners and the existing Cloudflare Pages project; free-plan limits still apply. See [Cloudflare's continuous deployment guide](https://developers.cloudflare.com/pages/how-to/use-direct-upload-with-continuous-integration/).

## Source

- `src/content.ts`: reviewed, approved public facts shared by the static pages and Twin.
- `scripts/render.ts`: homepage, four case studies, and privacy page.
- `src/style.css`: mineral/teal themes, responsive work panels, scroll reveals, and native CSS motion.
- `src/main.ts`: saved theme/motion preferences, animated native chat dialog, streamed responses, stop/retry states, and contact form.
- `src/stream.ts`: shared SSE decoder; handles fragmented UTF-8 and CRLF.
- `functions/api/`: public configuration, chat relay, lead notification, validation, and Turnstile verification.
- `public/ahmad-nouh-public-cv.pdf`: reviewed public CV without a phone number.
- `checks/site.test.ts`: Node's built-in checks for content boundaries, SSE, request validation, provider errors, and lead behavior.

The initial theme follows the device. The sun/moon switch saves a manual choice; the footer restores device theme. Motion respects reduced-motion preferences unless the visitor explicitly enables it, and can be paused.

The Twin sends a short conversation and approved public facts to Groq. Only answer text is streamed; output is bounded, interrupted answers are marked, and only completed answers enter subsequent context. Chat history stays in page memory; the site does not store transcripts on a server.

## Service secrets

Copy `.dev.vars.example` to `.dev.vars` and supply:

- `GROQ_API_KEY`
- `RESEND_API_KEY`
- `TURNSTILE_SITE_KEY`
- `TURNSTILE_SECRET_KEY`

The file is ignored. Never prefix a secret with `VITE_`.

Production `SITE_ORIGIN` and `LEAD_FROM` are configured in `wrangler.toml`. Resend's sending domain must be verified; Turnstile must allow the exact production hostname. Both APIs check the request hostname, Origin, Turnstile hostname/action, and input limits. Emails are sent only after explicit form submission, to a fixed recipient with the visitor's address as reply-to.

For local form testing, separately allow `localhost` in Turnstile, use `http://localhost:8788`, and set the local `.dev.vars` `SITE_ORIGIN` to that exact origin. Production hostname validation is never bypassed.

To update production service bindings after a local Wrangler sign-in:

```sh
node scripts/sync-secrets.mjs
npm run deploy
```

The helper sends only the four service bindings through stdin. It does not print their values.

## Public repository boundaries

Only the standalone portfolio source, public assets, and CI configuration belong here. Dependencies, generated output, local credentials, review evidence, and private CV-generation tooling are ignored. The build uses the included public PDF and does not depend on any private workspace files.

Public copy preserves the distinction between Blink's delivered recommendations and beta agent, MENT's measured pipeline improvements and separate graph/agent contributions, and Lableb's model research and production spam service. No employer screenshots or internal diagrams are included.

Fonts are self-hosted; their OFL licenses are included under `public/fonts/`.
